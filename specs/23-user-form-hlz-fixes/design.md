# Design — HLZ-50..54

- HLZ-54: `.topbar-menu-btn` display rule is unlayered CSS, which beats Tailwind v4 utilities (`lg:hidden`, inside `@layer utilities`). Move the rule into `@layer components` so utilities win.
- HLZ-52: fix types at the source: nullable ids in S01 handled with `?? undefined`; S02 password mode typed as the union; `GuardianProfileData.work_phone_dial` added to the type mirror; `AddressItem.country` removed from the completion check (field is `country_id`); `autosave` typed with a shared `AutosaveState` in `types/userForm.ts`.
- HLZ-53: `IntersectionObserver` callbacks only receive changed entries. Keep a `Set` of currently intersecting section ids across callbacks and pick the topmost (document order) of the set. Additionally a short last section can never reach the activation band by scrolling, so the observer band is widened and, when the page is scrolled to the bottom, the last section is activated.
- HLZ-51: the autosave `watch` lived only in the orphan `useUserFormPage` composable; `Edit.vue` uses `useUserEditForm`, which had no watcher. Add a deep watch on `formData` in `useUserEditForm` (simulated draft indicator per spec: "Guardando…" 600ms -> "Guardado"), skipped while a real section save is in flight. New `UserFormAutosave.vue` renders the indicator with relative time ("Guardado hace Xs") ticking every second; used by Header and Footer.
- HLZ-50: Create.vue uses `useUserFormPage` (role, formData, completion, autosave) + `UserFormHeader` + `UserFormFooter`. `computeCompletion` accepts the list of renderable sections. Submit enabled when `pct >= 50` and required fields (first/last name, email, role) are present. Header hides the "cambiar" button in Edit.
